# Web-Audit

A portfolio repository for web security audit and security risk management learning resources.

## Security risk and control assurance

[Read the Security Risk Assessment and Control Assurance Playbook](docs/security-risk-assessment-playbook.md).

The playbook includes assessment scoping, risk ownership, an illustrative rating method, control evidence and sampling, a risk register template, a fictional worked example, engineering handoff guidance and monitoring measures. References include NIST and OWASP resources.

This is an illustrative learning resource developed with AI assistance. The example is fictional and does not represent client work, a certification or an independent audit opinion.
